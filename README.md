# Skyport — установщики

Skyport ставит на ваш сервер WireGuard, AmneziaWG и панель управления, а дальше помогает выдавать профили для устройств.

**Скачать:** откройте [последний релиз](https://github.com/BEREZA911/skyport-releases/releases/latest) и возьмите:

- **Windows** — `Skyport-Setup-<версия>.exe`
- **macOS** (Intel и Apple Silicon) — `Skyport-<версия>-mac.dmg`

Уже установленное приложение обновляется само: на Windows новая версия скачивается в фоне, на Mac приложение подскажет, что вышла новая версия.

### Первый запуск

- **Windows:** если появится «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае» (у установщика нет платной подписи).
- **macOS:** перетащите Skyport в «Программы», затем первый раз откройте его правой кнопкой → «Открыть» → «Открыть».

Здесь лежат только готовые установщики.
